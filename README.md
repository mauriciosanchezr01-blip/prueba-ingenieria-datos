# Prueba Ingeniería de Datos - Tuya

Solución a la prueba técnica. Cada carpeta corresponde a un ejercicio, con
su propio código y README explicando el desarrollo.

## Contenido

### `ejercicio_1/`
Pipeline que crea, normaliza y valida un dataset de teléfonos de clientes.
Incluye tests con pytest y un workflow de CI en GitHub Actions que corre
los tests automáticamente en cada push.

### `ejercicio_2/`
Propuesta conceptual de un mecanismo para hacer seguimiento a la calidad
de los datos de teléfonos (KPI's, trazabilidad) de cara a los equipos de
negocio.

### `ejercicio_3/`
Consultas SQL para identificar rachas de saldo de clientes por nivel de
deuda, a partir de la información de `rachas.xlsx`.

### `ejercicio_4/`
Scripts en Python (solo librerías estándar) para recorrer archivos HTML,
convertir sus imágenes a base64 y generar una copia con las imágenes
incrustadas.
